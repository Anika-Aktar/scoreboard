# Scoreboard Game 🏆

A simple and interactive scoreboard game built using HTML, CSS, and JavaScript. Keep track of scores with an easy-to-use interface.

## ✨ Features
- Interactive score tracking
- Score updates using JavaScript
- Clean and simple user interface
- Responsive styling with CSS

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Anika-Aktar/scoreboard.git
   ```
2. Open `index.html` in your browser.
